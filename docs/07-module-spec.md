## Objectif du module

Mener un projet Data Science de la **phase de compréhension métier au déploiement**.

## Évaluation

| Composante | Pondération |
|-----------|-------------|
| Note Individuelle | 70% |
| Note Groupe | 30% |

**Conditions spéciales :**
- Note Individuelle < 10 → Note Finale = Note Individuelle
| Diff Individuel - Groupe < 3 → 60% Individuel + 40% Groupe
- Diff Groupe - Individuel > 3 → 90% Individuel + 10% Groupe

## Les 4 Phases

### Phase 1 : Compréhension métier et approche analytique (3h + 6h)
- Identifier besoins fonctionnels et objectifs métiers
- Identifier besoins non fonctionnels/techniques
- Identifier contraintes d'exploitation
- **Rapport + Présentation**

### Phase 2 : Collecte et compréhension des données (3h + 6h)
- Collecter les données
- Critiquer la qualité des données
- Traiter pour améliorer la qualité
- **Rapport + Présentation + Notebook**

### Phase 3 : Modélisation des données (15h)
- Choisir modèles (ML/DL/NLP/Agentic IA/GenAI/Séries temporelles)
- Argumenter et défendre le choix des modèles
- Évaluer les performances
- **Notebook + Rapport + Présentation**

### Phase 4 : Déploiement (9h)
- Choisir mesures de performance
- Développer supports de prise de décision
- **Rapport + Notebook + Présentation**
