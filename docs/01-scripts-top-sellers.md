## Structure commune de chaque script

Chaque produit suit le même format :

```
Script Flash : "Bonjour Docteur, 20 secondes… Je vous laisse une fiche et je repasse. D'accord ?"
Script Standard : Permission → Q1/Q2 → Synthèse → 2-3 arguments → Closing test 2-3 cas → retour.
Suivi CRM : J+7 retour tolérance/observance ; J+14 décision & prochaine action.
```

**Méthode A-C-R-V pour les objections :**
- **A**ccueillir : "Je comprends"
- **C**larifier : "Quand vous dites X, c'est plutôt… ?"
- **R**épondre : fait + preuve courte + option pratique
- **V**alider : "Est-ce que cela répond à votre point ?"

**Message cœur :** Aider à couvrir les besoins en fer chez l'adulte selon profil, avec une approche pratique d'observance.

- Fatigue ressentie liée à des carences suspectées (selon avis médical)

### Questions découverte
- Sur vos patients, le frein principal c'est plutôt tolérance digestive ou observance ?

### Argumentation
- Bénéfice pratique : prise simple + routine facile
- Tolérance/observance : conseils de prise pour améliorer l'adhésion
- Positionnement : profils où l'apport en fer est pertinent selon le contexte

### Objections & réponses (A-C-R-V)

| Objection | Clarifier | Répondre + Valider |
|-----------|-----------|-------------------|
| J'ai mes habitudes | Sur quels patients vous êtes le moins satisfait ? | Justement, positionnement en plan B sur ce profil + test + suivi J+7/J+14. |
| Trop d'intolérance | C'est plutôt nausées, constipation, ou autre ? | Conseils de prise + adaptation du schéma ; si besoin je vous partage la fiche. |

## Instructions pour ALIA

Lors de l'utilisation de ces scripts par l'avatar ALIA :

1. **Adapter le ton** selon le niveau de compétence (Débutant = scripté, Expert = improvisé)
2. **Respecter la conformité** : jamais inventer de donnée, toujours renvoyer à la fiche produit
3. **Utiliser les questions de sondage** avant d'argumenter
4. **Toujours traiter les objections** par la méthode A-C-R-V
5. **Conclure par un micro-engagement** (test 2-3 patients, retour J+7)
6. **Le suivi CRM est obligatoire** : J+7 retour tolérance/observance, J+14 décision
